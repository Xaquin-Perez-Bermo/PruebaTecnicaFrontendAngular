# Mini tienda de móviles (Angular 21)

Prueba técnica front-end: SPA para comprar dispositivos móviles con dos vistas
(listado de productos y detalle). Resuelto con **Angular 21**.

## Requisitos

- Node 20.19+ / 22.12+ / 24+
- npm

## Instalación

```bash
npm install
```

## Scripts


* `npm start`: modo desarrollo (http://localhost:4200)
* `npm run build`: compilación para producción (`dist/`)
* `npm test`: lanza los tests (Vitest)
* `npm run lint`: comprobación de código (ESLint)
